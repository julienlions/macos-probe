# sonde-voie-c

Dépôt **jetable et public**. Il ne contient aucune ligne de Wrap : seulement les
deux questions qu'une machine Windows ne peut pas trancher.

1. libjpeg-turbo (C) et jpegli (C++) se construisent-ils sur macOS arm64,
   macOS Intel, Linux et Windows ?
2. Le décodage rend-il **les mêmes octets** sur toutes ces cibles ?

La seconde décide si l'identité d'un asset dépend de la machine du client.

Public exprès : les minutes macOS de GitHub Actions sont gratuites et illimitées
sur un dépôt public, facturées ×10 sur un dépôt privé.

Se supprime sans regret une fois la réponse obtenue.
